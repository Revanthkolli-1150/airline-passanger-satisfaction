# Reports Directory

This directory stores cross-validation metrics, model comparison tables, and evaluation curves.

## Files
- `model_comparison.csv`: Tabular comparison of validation metrics (Validation ROC-AUC, Accuracy, Precision, Recall, F1-Score, Training Duration).
- `evaluation_metrics.json`: Detailed evaluation payload containing confusion matrices, ROC curve false positive rate (FPR) and true positive rate (TPR) coordinate points, and metadata.
